# Airdrop Tracker
A simple tracker for free airdrop farming. Free-only: no capital, no deposits, no trading, no seed phrase, no private key.
## Rules
- Only free and legit airdrops, all networks.
- Never share a seed phrase or private key.
- Never pay, deposit, or send funds to claim.
- Avoid X/Twitter tasks when possible; use phone-only steps for X.
